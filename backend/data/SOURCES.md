# Data sources

## `ragas.json` — raga reference table

Generated by `scripts/build_raga_table.py` from:

- **Wikipedia, "List of Janya ragas"** (raw wikitext snapshot fetched 2026-11-17,
  kept at `sources/wikipedia_list_of_janya_ragas.wikitext`).
  <https://en.wikipedia.org/wiki/List_of_Janya_ragas> — text available under
  CC BY-SA 4.0. Arohana/avarohana scale definitions are factual musical data.
  The list contains all 72 melakartas, each followed by its janya ragas.

Local adjustments, applied by the build script:

- `raga_aliases.json`: common performance names and spellings
  (e.g. Thodi → Hanumatodi, Shankarabharanam → Dhirasankarabharanam,
  Kalyani → Mechakalyani). These aliases always win over a clashing name.
- `raga_overrides.json`: corrections to known errors in the source
  (currently Navaroj, Atana, and the "Sahana (Original)" row under mela 22).
- Rows that fail validation (e.g. scales with no Sa) are skipped and reported.
- When one name appears under several melas, the occurrence with its own
  Wikipedia article keeps the plain name; others become "Name (mela N)".

Rebuild:

    uv run python scripts/build_raga_table.py \
        --wikitext data/sources/wikipedia_list_of_janya_ragas.wikitext \
        --aliases data/raga_aliases.json --overrides data/raga_overrides.json \
        --out data/ragas.json
